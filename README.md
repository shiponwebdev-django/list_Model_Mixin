DRF Model Mixins & GenericAPIView Exploration

This project demonstrates how to build a complete CRUD API in Django REST Framework using GenericAPIView and DRF's built-in Model Mixins (ListModelMixin, CreateModelMixin, RetrieveModelMixin, UpdateModelMixin, and DestroyModelMixin). It covers structured models, serializers, modular CBVs (Class-Based Views), and RESTful URL routing.
